# Receipe_Recommender_Assignment

Background: A food recipe website would like to develop a recipe recommendation engine to increase user engagement which can result in more business opportunities such as collaborations and promotions on the website. The higher the user engagement on the website, more is the likelihood to get more business opportunities such as promotions and collaborations, and ultimately higher would be the impact on revenue generated from the website.

Goal: This assignment is implemented on Amazon AWS cloud environment with various services such as S3 (dataset storage), EMR on EC2 (Map-Reduce computation), VPC (network), IAM (access management). It involves feature engineering to create new attributes for an effective recipe recommender system. PySpark framework is applied for the implmentation.

Deliverables: Python implementation with assertion check at multiple stages of development to confirm the progress being right track and approapriate comments for all the steps involved.
